# 🎓 HEC Attendance Wizard

A modern, animated **HEC-based attendance calculator** built with **React**.  
This tool helps students quickly calculate **required attendance** and **allowed absences** based on credit hours and weekly classes.

🌐 **Live Demo:**  
https://gul310.github.io/hec-attendance-wizard

---

## ✨ Features

- ✅ HEC-compliant 75% attendance rule
- 🎯 Credit Hours: 1 – 4
- 📅 Classes per week: 1 or 2
- 📊 Attendance progress bar
- 🌙 Light / Dark mode
- 🎬 Smooth animations & transitions
- 📱 Mobile-friendly UI
- 📋 Copy results with one click

---

## 🛠️ Built With

- React (Create React App)
- Framer Motion (animations)
- GitHub Pages (deployment)
